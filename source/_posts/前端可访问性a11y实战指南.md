## 前言

全球有超过 10 亿残障人士。可访问性（Accessibility，简称 a11y）不仅仅是"有爱心"——它直接关系到你的产品能用多少人在用。

很多 a11y 问题只需少量改动就能解决。

---

## 一、语义化 HTML（成本最低的 a11y）

```html
<!-- ❌ 全部用 div 模拟 -->
<div class="button" onclick="submit()">提交</div>
<div class="nav">
  <div onclick="goHome()">首页</div>
</div>

<!-- ✅ 原生语义化标签（自带键盘交互和屏幕阅读器支持）-->
<button type="submit">提交</button>
<nav>
  <a href="/">首页</a>
</nav>
```

---

## 二、ARIA 属性

当无法使用语义化标签时，用 ARIA 补充：

```html
<!-- 自定义复选框 -->
<div
  role="checkbox"
  aria-checked="false"
  tabindex="0"
  @click="toggle"
  @keydown.space="toggle"
>
  {{ label }}
</div>

<!-- 加载状态 -->
<div aria-live="polite">加载中，请稍候...</div>

<!-- 错误提示关联 -->
<label for="email">邮箱</label>
<input id="email" aria-describedby="email-error" />
<p id="email-error" role="alert">邮箱格式不正确</p>
```

## 三、键盘导航

```css
/* 焦点样式（至关重要）*/
:focus-visible {
  outline: 2px solid #1890ff;
  outline-offset: 2px;
}

/* ❌ 不要清除 outline（让键盘用户无法定位）*/
:focus { outline: none; }
```

```html
<!-- tabindex 控制 Tab 键顺序 -->
<button tabindex="0">正常顺序</button>
<button tabindex="1">优先聚焦</button>
<div tabindex="-1">无法通过 Tab 聚焦</div>
```

## 四、颜色对比度

```markdown
WCAG 2.1 标准要求：
- 正文文本：对比度 ≥ 4.5:1
- 大文本（18px+ 粗体/24px+）：对比度 ≥ 3:1
- 图标和交互元素：对比度 ≥ 3:1
```

```css
/* ❌ 对比度不足 */
.light-text { color: #ccc; background: #fff; }  /* 1.8:1 */

/* ✅ 符合标准 */
.normal-text { color: #333; background: #fff; }  /* 9.5:1 */
```

## 五、图片与媒体

```html
<!-- 必填：alt 属性 -->
<img src="chart.png" alt="2024年销售额柱状图——Q1 120万，Q2 180万" />

<!-- 装饰性图片 -->
<img src="divider.png" alt="" />  <!-- alt 留空 -->

<!-- 视频 -->
<video controls>
  <source src="tutorial.mp4" />
  <track kind="captions" src="tutorial.vtt" srclang="zh" />
</video>
```
