## 前言

Claude Code 是 Anthropic 推出的**命令行 AI 编程代理**（Agentic Coding Tool）。与传统的 AI 聊天不同，Claude Code 能直接操作你的代码库——读取文件、编辑代码、运行命令、管理 Git。

---

## 一、核心能力

### 1.1 理解整个项目

Claude Code 会自动扫描项目结构，理解文件间的依赖关系：

```
项目扫描 → 理解目录结构 → 分析文件依赖 → 上下文感知
```

这意味着你可以直接说：
> "帮我看看这个项目的性能瓶颈在哪里"

它就能分析整个项目，找出问题。

### 1.2 代码编辑

```bash
# 直接告诉 Claude Code 要改什么
# "把这个函数改成异步的，并添加错误处理"
# "给这个组件添加单元测试"
# "把这段代码提取为公共函数"
```

Claude Code 会：
1. 读取相关文件
2. 编辑代码
3. 创建新文件（如果需要）
4. 验证结果

### 1.3 执行命令

```bash
# Claude Code 可以直接运行命令
# "运行测试看看有没有报错"
# "安装 lodash 依赖"
# "构建项目"
```

## 二、使用技巧

### 2.1 清晰的任务描述

```markdown
## ❌ 模糊
"优化这段代码"

## ✅ 具体
"优化 src/utils/format.js 中的 formatDate 函数：
- 当前使用 moment.js，改为 dayjs
- 添加时区支持
- 添加 TypeScript 类型定义
- 更新所有引用该函数的地方"
```

### 2.2 分步骤执行

```markdown
"帮我做三件事：
1. 先在 src/utils/ 下创建一个 helpers.js 文件
2. 把 fetchData 函数移过去
3. 更新所有引用路径"
```

### 2.3 使用 Plan 模式

```markdown
"先用 plan 模式分析这个需求，让我确认后再执行：

需要在用户页面添加一个导出 CSV 功能：
- 点击按钮导出当前筛选条件下的用户列表
- 包含姓名、邮箱、注册时间
- 文件名格式：users_YYYYMMDD.csv"
```

## 三、适用场景

| 场景 | 推荐用法 |
|------|---------|
| **重构代码** | 描述目标，让 AI 执行具体修改 |
| **添加功能** | 描述需求，AI 生成代码并集成 |
| **修复 Bug** | 描述问题，AI 定位并修复 |
| **编写测试** | AI 分析代码后生成测试用例 |
| **代码审查** | AI 在 commit 前检查代码质量 |

---

## 四、注意事项

```markdown
1. 版本控制
   - 让 AI 操作前先 commit，方便回滚
   - 审查 AI 生成的所有代码再合并

2. 上下文限制
   - 避免一次性要求操作太多文件
   - 拆分为多个小任务更可靠

3. 安全
   - 不要在 prompt 中包含敏感信息（API Key、密码）
   - AI 生成的依赖要检查版本安全性

4. 验证
   - 始终运行测试验证 AI 的修改
   - 检查是否引入了不必要的依赖
```

---

## 总结

```markdown
Claude Code 是强大的编程助手，但要发挥最大价值：

✅ 要这样做：
- 给出清晰具体的任务描述
- 分步骤、分批执行
- 审查所有代码变更
- 用版本控制兜底

❌ 不要这样做：
- 一次性提太多需求
- 不加审查直接合并
- 在 prompt 中泄露敏感信息

AI 编程工具是「加速器」不是「自动驾驶」——最终的责任在开发者。
```
