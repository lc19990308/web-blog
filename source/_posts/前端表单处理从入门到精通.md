## 前言

表单是 Web 应用中最基本也最复杂的交互形式之一。一个简单的注册表单，可能涉及：

- 字段验证（格式、长度、必填）
- 联动逻辑（选择国家后加载城市）
- 动态增减字段（添加多个标签）
- 错误状态管理
- 提交防重

本文将以 **React Hook Form + Zod** 为主线，系统讲解现代前端表单处理。

---

## 一、受控 vs 非受控组件

### 1.1 受控组件

```tsx
function ControlledForm() {
  const [value, setValue] = useState('')

  // ✅ 数据在 React 中，实时可控
  // ❌ 每次输入都触发 setState → 重渲染
  return <input value={value} onChange={e => setValue(e.target.value)} />
}
```

### 1.2 非受控组件

```tsx
function UncontrolledForm() {
  const inputRef = useRef<HTMLInputElement>(null)

  // ✅ 数据在 DOM 中，不触发额外重渲染
  // ❌ 需要时手动读取值
  return <input ref={inputRef} defaultValue="hello" />
}
```

**React Hook Form 的核心优化：** 默认使用非受控组件，减少不必要的渲染。

## 二、React Hook Form 入门

### 2.1 基础用法

```tsx
import { useForm } from 'react-hook-form'

type FormData = {
  email: string
  password: string
}

function LoginForm() {
  const {
    register,
    handleSubmit,
    formState: { errors }
  } = useForm<FormData>()

  const onSubmit = (data: FormData) => {
    console.log(data) // { email: '...', password: '...' }
  }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('email', { required: '请输入邮箱' })} />
      {errors.email && <span>{errors.email.message}</span>}

      <input type="password" {...register('password', {
        required: '请输入密码',
        minLength: { value: 6, message: '至少 6 位' }
      })} />
      {errors.password && <span>{errors.password.message}</span>}

      <button type="submit">登录</button>
    </form>
  )
}
```

### 2.2 register 返回了什么？

```ts
register('email', { required: true })
// 返回
{
  onChange: (e) => void,
  onBlur: (e) => void,
  ref: (el) => void,
  name: 'email'
}
```

通过 `ref` 实现非受控——Hook Form 直接读取 DOM 的值，不通过 React state。

## 三、Zod 验证

### 3.1 定义 Schema

```ts
import { z } from 'zod'

const loginSchema = z.object({
  email: z.string().email('邮箱格式不正确'),
  password: z.string().min(6, '密码至少 6 位').max(32),
  rememberMe: z.boolean().optional()
})

type LoginFormData = z.infer<typeof loginSchema>
```

### 3.2 集成到 Hook Form

```tsx
import { zodResolver } from '@hookform/resolvers/zod'

const { register, handleSubmit, formState: { errors } } = useForm<LoginFormData>({
  resolver: zodResolver(loginSchema)
})
```

## 四、进阶技巧

### 4.1 字段联动

```tsx
function AddressForm() {
  const { watch, setValue } = useForm()

  const country = watch('country') // 监听 country 字段

  useEffect(() => {
    if (country === 'China') {
      setValue('cities', ['北京', '上海', '深圳'])
      // 或者请求 API
      fetchCities(country).then(cities => setValue('cities', cities))
    }
  }, [country, setValue])

  return (
    <select {...register('country')}>
      <option value="China">中国</option>
      <option value="USA">美国</option>
    </select>
  )
}
```

### 4.2 动态字段

```tsx
import { useFieldArray } from 'react-hook-form'

function TagInput() {
  const { register, control } = useForm()
  const { fields, append, remove } = useFieldArray({
    control,
    name: 'tags'
  })

  return (
    <div>
      {fields.map((field, index) => (
        <div key={field.id}>
          <input {...register(`tags.${index}.value`)} />
          <button onClick={() => remove(index)}>删除</button>
        </div>
      ))}
      <button onClick={() => append({ value: '' })}>添加标签</button>
    </div>
  )
}
```

### 4.3 表单状态

```tsx
const {
  formState: {
    isDirty,     // 是否被修改过
    dirtyFields, // 哪些字段被修改了
    isValid,     // 是否通过验证
    isLoading,   // 是否正在加载默认值
    isSubmitting // 是否正在提交
  }
} = useForm()
```

## 五、性能优化

React Hook Form 的性能优势源于：

1. **非受控组件** —— 每个字段独立，不会因其他字段变化而重渲染
2. **隔离更新** —— `errors` 对象在字段级别独立更新
3. **批量订阅** —— 多个字段可以批量监听，减少订阅次数

```tsx
// 如果必须使用受控组件
<input
  {...register('name')}
  onChange={(e) => {
    // 自定义逻辑
    logAnalytics(e.target.value)
    // 然后调用 register 的 onChange
    register('name').onChange(e)
  }}
/>
```
