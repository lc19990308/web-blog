## 前言

最隐蔽的 Bug 往往出现在**边界情况**：

```
接口返回的数据格式不对 → 页面白屏
某个图片加载失败 → 整个列表不显示
用户快速点击两次 → 重复提交
第三方 SDK 加载失败 → 整个页面崩溃
```

好的前端应用，**即使在出错时，也不能让用户面对白屏**。

## 一、全局异常捕获

```javascript
// main.js——兜底方案
// 1. 未捕获的 Promise 错误
window.addEventListener('unhandledrejection', (event) => {
  console.error('未捕获的 Promise 拒绝:', event.reason)
  // 上报到 Sentry
  sendToSentry(event.reason)
  // 阻止浏览器打印默认错误
  event.preventDefault()
})

// 2. 同步运行时错误
window.onerror = (message, source, lineno, colno, error) => {
  console.error('全局错误:', message)
  sendToSentry(error)
  return true  // 阻止默认错误处理
}

// 3. 资源加载失败（图片、脚本、CSS）
window.addEventListener('error', (event) => {
  if (event.target.tagName) {
    console.warn(`资源加载失败: ${event.target.src || event.target.href}`)
    // 替换为占位图
    if (event.target.tagName === 'IMG') {
      event.target.src = '/images/placeholder.svg'
    }
  }
}, true)  // 捕获阶段
```

## 二、Vue 的错误处理

```javascript
// main.js
const app = createApp(App)

// 全局错误处理
app.config.errorHandler = (err, instance, info) => {
  console.error('Vue 错误:', err)
  console.error('错误来源:', info)  // 'render' | 'setup' | 'event handler'

  // 上报错误
  sendToSentry(err, { component: instance?.$options?.name, info })

  // 生产环境下显示降级 UI
  if (import.meta.env.PROD) {
    showFallbackUI()
  }
}

// 全局警告处理
app.config.warnHandler = (msg, instance, trace) => {
  console.warn('Vue 警告:', msg)
}

// 组件级别的错误捕获
app.component('ErrorBoundary', {
  template: `
    <div v-if="error">
      <h3>组件渲染出错</h3>
      <p>{{ error.message }}</p>
      <button @click="reset">重试</button>
    </div>
    <slot v-else />
  `,
  data() { return { error: null } },
  errorCaptured(err) {
    this.error = err
    return false  // 阻止错误继续冒泡
  },
  methods: {
    reset() { this.error = null }
  },
})
```

## 三、图片加载失败降级

```vue
<script setup>
import { ref } from 'vue'

const props = defineProps({ src: String, fallback: String })
const imgError = ref(false)
const loadError = ref(false)
</script>

<template>
  <div class="image-wrapper">
    <!-- 尝试加载原图 -->
    <img
      v-if="!imgError"
      :src="src"
      @error="imgError = true"
      @load="loadError = false"
    />
    <!-- 第一级降级：使用 fallback 图片 -->
    <img
      v-else-if="!loadError && fallback"
      :src="fallback"
      @error="loadError = true"
    />
    <!-- 第二级降级：显示占位 UI -->
    <div v-else class="image-placeholder">
      <span>📷</span>
      <p>图片加载失败</p>
    </div>
  </div>
</template>
```

## 四、API 请求的优雅降级

```javascript
// 封装请求——自动降级
async function fetchWithFallback(url, options = {}) {
  const { fallbackData = null, retries = 2, timeout = 10000 } = options

  for (let i = 0; i <= retries; i++) {
    try {
      const controller = new AbortController()
      const timer = setTimeout(() => controller.abort(), timeout)

      const res = await fetch(url, {
        ...options,
        signal: controller.signal,
      })
      clearTimeout(timer)

      if (!res.ok) throw new Error(`HTTP ${res.status}`)
      return await res.json()

    } catch (err) {
      if (i === retries) {
        console.warn(`请求失败，使用降级数据: ${url}`)
        return fallbackData  // 返回默认数据
      }
      // 指数退避重试
      await new Promise(r => setTimeout(r, 1000 * Math.pow(2, i)))
    }
  }
}

// 使用：即使接口挂了，页面也能正常渲染
const userData = await fetchWithFallback('/api/user/profile', {
  fallbackData: { name: '游客', avatar: '/default-avatar.png' },
})
```

## 五、降级 UI 组件

```vue
<script setup>
defineProps({ title: String, message: String })

const emit = defineEmits(['retry'])
</script>

<template>
  <div class="error-fallback" role="alert">
    <div class="error-icon">⚠️</div>
    <h3>{{ title || '出了点问题' }}</h3>
    <p>{{ message || '请稍后重试' }}</p>
    <div class="actions">
      <button class="btn btn-primary" @click="emit('retry')">
        重试
      </button>
      <button class="btn btn-secondary" @click="$router.back()">
        返回
      </button>
    </div>
  </div>
</template>
```

## 六、错误处理体系总结

```markdown
┌─────────────────────────────────────────────┐
│          错误处理体系                         │
│                                             │
│  第一层：try/catch          代码级防御         │
│  第二层：组件错误边界        组件级隔离         │
│  第三层：全局 errorHandler  应用级兜底         │
│  第四层：window.onerror     浏览器级兜底       │
│                                             │
│  降级策略：                                   │
│  数据加载失败 → 显示默认数据                   │
│  图片加载失败 → 显示占位图                     │
│  组件渲染失败 → 显示降级 UI + 重试按钮          │
│  页面整体崩溃 → 显示全局错误页                  │
└─────────────────────────────────────────────┘
```

**核心理念：** 永远不要让用户面对白屏。一个好的错误提示，胜过一场无声的崩溃。
