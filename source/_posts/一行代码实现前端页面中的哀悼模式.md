## 前言

遇到哀悼日，只需要一行 CSS 就能将整个网站变为灰色调。这背后的技术是 CSS 的 `filter` 属性——一个强大的视觉处理工具。

---

## 一、网站灰度化

```css
/* 一行代码实现全站哀悼模式 */
html {
  filter: grayscale(100%);
  /* 兼容低版本浏览器 */
  -webkit-filter: grayscale(100%);
  -moz-filter: grayscale(100%);
  -ms-filter: grayscale(100%);
  -o-filter: grayscale(100%);
}
```

**效果：** 页面所有颜色消失，变为黑白灰。

### 兼容方案

```css
/* 如果 filter 不支持，使用 SVG 方案 */
html {
  filter: url("data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg'><filter id='gray'><feColorMatrix type='saturate' values='0'/></filter></svg>#gray");
}
```

## 二、filter 属性全解

`filter` 可以将多种视觉效果应用到元素上：

### 2.1 常用滤镜

```css
.element {
  /* 灰度 */
  filter: grayscale(100%);       /* 完全黑白 */

  /* 模糊 */
  filter: blur(4px);             /* 毛玻璃效果 */

  /* 亮度 */
  filter: brightness(150%);      /* 更亮 */
  filter: brightness(50%);       /* 更暗 */

  /* 对比度 */
  filter: contrast(200%);        /* 更高对比 */

  /* 阴影 */
  filter: drop-shadow(2px 4px 6px rgba(0,0,0,0.5));

  /* 色相旋转 */
  filter: hue-rotate(90deg);     /* 颜色偏移 */

  /* 反色 */
  filter: invert(100%);          /* 照片底片效果 */

  /* 饱和度 */
  filter: saturate(200%);        /* 色彩更鲜艳 */
  filter: saturate(0%);          /* 去色 = grayscale */
}

/* 组合使用 */
.filter-combo {
  filter: brightness(80%) contrast(150%) saturate(120%);
}
```

### 2.2 滤镜速查

| 函数 | 默认值 | 取值范围 | 效果 |
|------|--------|---------|------|
| `grayscale()` | 0 | `0-1` 或 `0%-100%` | 灰度 |
| `blur()` | 0 | `0px+` | 高斯模糊 |
| `brightness()` | 1 | `0+` | 亮度 |
| `contrast()` | 1 | `0+` | 对比度 |
| `drop-shadow()` | - | 同 `box-shadow` | 投影 |
| `hue-rotate()` | 0deg | `0deg-360deg` | 色相旋转 |
| `invert()` | 0 | `0-1` 或 `0%-100%` | 反色 |
| `opacity()` | 1 | `0-1` | 透明度 |
| `saturate()` | 1 | `0+` | 饱和度 |
| `sepia()` | 0 | `0-1` | 怀旧色调 |

## 三、实战场景

### 3.1 图片 hover 效果

```css
img {
  transition: filter 0.3s;
}

/* 鼠标悬停变亮 */
img:hover {
  filter: brightness(110%) contrast(110%);
}

/* 黑白照片 hover 恢复彩色 */
.grayscale-img {
  filter: grayscale(100%);
  transition: filter 0.5s;
}
.grayscale-img:hover {
  filter: grayscale(0%);
}
```

### 3.2 加载占位图模糊

```css
/* 图片加载完成前显示模糊版本 */
.placeholder {
  filter: blur(20px);
  transition: filter 0.3s;
}
.placeholder.loaded {
  filter: blur(0);
}
```

### 3.3 暗色模式图片适配

```css
/* 暗色模式下图片降低亮度 */
@media (prefers-color-scheme: dark) {
  img { filter: brightness(0.8); }
}
```

## 四、filter vs box-shadow

`drop-shadow` 与 `box-shadow` 的区别：

```css
/* box-shadow：只给元素盒子加阴影（会裁剪透明部分） */
.box { box-shadow: 2px 2px 5px rgba(0,0,0,0.3); }

/* drop-shadow：给元素实际内容加阴影（包括透明 PNG） */
.png-logo { filter: drop-shadow(2px 2px 5px rgba(0,0,0,0.3)); }
```

**示例：** 一个圆形 PNG 图片，`box-shadow` 只给矩形区域加阴影，`drop-shadow` 会给圆形边缘加阴影。

## 五、性能与兼容性

### 5.1 性能建议

```css
/* ✅ 推荐：在单独的层上使用 filter */
.filter-layer { /* 减少重绘区域 */ }

/* ❌ 避免：对大量元素使用 filter */
.items > * { filter: grayscale(50%); }  /* 1000 个元素，卡顿 */
```

### 5.2 兼容性

| 浏览器 | 支持情况 |
|--------|---------|
| Chrome 18+ | ✅ 完全支持 |
| Firefox 35+ | ✅ 完全支持 |
| Safari 6+ | ✅ 带 -webkit 前缀 |
| Edge 12+ | ✅ 完全支持 |
| IE | ❌ 不支持（使用 SVG 方案）|
