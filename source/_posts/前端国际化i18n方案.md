## 前言

国际化（Internationalization，简称 i18n）不仅仅是翻译文本，还要处理：**日期格式、数字格式、货币符号、文案拼接、复数规则**——不同语言这些规则完全不同。

---

## 一、vue-i18n（Vue 项目推荐）

```bash
npm install vue-i18n
```

```javascript
// i18n/index.js
import { createI18n } from 'vue-i18n'

const messages = {
  en: {
    hello: 'Hello',
    welcome: 'Welcome, {name}!',
    cart: 'Cart | Cart ({count})',
    login: { title: 'Login', btn: 'Sign In' },
    dateFormat: 'dd/MM/yyyy',
  },
  zh: {
    hello: '你好',
    welcome: '欢迎, {name}！',
    cart: '购物车 | 购物车 ({count})',
    login: { title: '登录', btn: '登录' },
    dateFormat: 'yyyy-MM-dd',
  },
}

const i18n = createI18n({
  locale: 'zh',                // 默认语言
  fallbackLocale: 'en',        // 降级语言
  messages,
})

export default i18n
```

```vue
<template>
  <p>{{ $t('hello') }}</p>
  <p>{{ $t('welcome', { name: user.name }) }}</p>
  <p>{{ $t('login.title') }}</p>
  <p>{{ $t('cart', cart.length) }}</p>
  <!-- 复数：英文 cart/cart(3)，中文都是 购物车 -->
</template>
```

## 三、日期和数字本地化

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { locale, d, n } = useI18n()

const price = 1234.56
const date = new Date('2024-07-12')
</script>

<template>
  <!-- 数字格式化 -->
  <p>{{ n(price, 'currency') }}</p>
  <!-- zh: ¥1,234.56 ｜ en: $1,234.56 -->

  <!-- 日期格式化 -->
  <p>{{ d(date, 'short') }}</p>
  <!-- zh: 2024-07-12 ｜ en: 07/12/2024 -->
</template>
```

## 四、语言切换

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

function switchLang(lang) {
  locale.value = lang
  localStorage.setItem('lang', lang)
  document.documentElement.lang = lang
}
</script>

<template>
  <select :value="locale" @change="switchLang($event.target.value)">
    <option value="zh">中文</option>
    <option value="en">English</option>
    <option value="ja">日本語</option>
  </select>
</template>
```
