前言

Sass（Syntactically Awesome Style Sheets）是目前使用最广泛的 CSS 预处理器。它的核心价值在于：变量、嵌套、混入、继承——让 CSS 从”声明式”走向”可编程”。

SCSS 是 Sass 的现代语法（CSS 超集，完全兼容 CSS），推荐使用。
