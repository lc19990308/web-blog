前端模块打包工具：从 Webpack 到 Vite

2022-12-064 分钟阅读更新于 2026-06-23

理解前端打包工具的核心概念（入口/输出/Loader/Plugin），对比 Webpack 与 Vite 的差异，掌握常见配置写法

前言

浏览器不支持模块化（import/export），也不支持 TypeScript、Sass 等语法。打包工具的作用就是将开发者友好的代码转换为浏览器可运行的格式。

一、核心概念

1.1 Webpack 五大核心

核心概念 作用 类比
Entry 入口文件 你的源代码
Output 打包结果 给浏览器的代码
Loader 转换非 JS 文件 翻译官
Plugin 增强功能 插件工具
Mode 环境区分 开发/生产

1.2 常用 Loader

Loader 作用
babel-loader ES6+ → ES5（兼容旧浏览器）
css-loader 解析 CSS 中的 @import/url()
style-loader CSS 注入到 <style> 标签
sass-loader Sass/SCSS → CSS
ts-loader TypeScript → JavaScript

四、Webpack vs Vite

4.1 核心差异

特性 Webpack Vite
开发启动 慢（需分析整个依赖图） 极快（按需编译）
热更新 慢（文件多时 >1s） 极快（ESM 直送）
构建 Rollup 打包（较慢） Rollup 打包（更快）
配置 复杂 简单
生态 丰富，插件多 丰富，兼容 Rollup 插件
最佳场景 复杂大型项目 新项目首选
