七、Canvas vs SVG

特性 Canvas SVG
类型 位图（像素） 矢量（形状）
性能 大量元素时更优 少量元素时更优
缩放 放大模糊 无限清晰
事件 ❌ 手动计算坐标 ✅ 每个元素可绑定事件
适用 游戏、图表、图像处理 图标、Logo、交互式图形

选型：

  • 需要操作每个图形（拖拽、点击）→ SVG
  • 大量图形（粒子、游戏）→ Canvas
  • 数据可视化 → 推荐 ECharts / D3.js（封装好了 Canvas 或 SVG）
